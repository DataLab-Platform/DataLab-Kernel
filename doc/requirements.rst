The `datalab-kernel` package requires the following Python modules:

.. list-table::
    :header-rows: 1
    :align: left

    * - Name
      - Version
      - Summary
    * - Python
      - >=3.10
      - Python programming language
    * - xeus-python
      - >=0.17.0
      - A wheel for xeus-python
    * - xeus-python-shell
      - >=0.6.0
      - The xeus-python core python logic.
    * - numpy
      - >=1.22
      - Fundamental package for array computing in Python
    * - httpx
      - >=0.25.0
      - The next generation HTTP client.
    * - h5py
      - >=3.0
      - Read and write HDF5 files from Python
    * - matplotlib
      - >=3.5
      - Python plotting package
    * - sigima
      - >=1.0
      - Scientific computing engine for 1D signals and 2D images, part of the DataLab open-source platform.
